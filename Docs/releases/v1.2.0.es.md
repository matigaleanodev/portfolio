# Portfolio v1.2.0

Renovación visual y de accesibilidad del portfolio y el blog, con lectura más cómoda, navegación por teclado y una presentación más clara de los proyectos.

## Cambios incluidos

- Listado del blog más compacto, búsqueda normalizada y orden accesible.
- Tipografía editorial, listas, tablas y bloques de código con resaltado, etiqueta de lenguaje y copia.
- Índice de artículos largos con enlaces disponibles también en el HTML prerenderizado.
- Enlaces internos con foco y scroll correctos, indicadores de foco visibles y fechas en español de Argentina.
- Formulario de suscripción corregido para enviar desde el formulario nativo y mostrar errores accesibles.
- Tarjetas de proyectos más compactas, arquitectura desplegable y nueva ilustración del proyecto Portfolio.
- Chat no modal con mejoras de foco, teclado, scroll y controles móviles.
- Evidencia visual antes/después y pruebas de navegador, accesibilidad, contenido sin JavaScript y zoom real al 200 % y 400 %.

## Compatibilidad

Se conserva la arquitectura static-first, las rutas públicas y los contratos existentes con la API y la capa cloud. La renovación no requiere migraciones de datos ni configuración nueva de servicios.

## Publicación

La rama `release/v1.2.0` reúne los cambios en un único commit. Su PR a `main` debe integrarse mediante squash. Al mergear el PR, el workflow de release crea el tag anotado `v1.2.0` sobre el commit integrado en `main` y publica estas notas en GitHub Releases. El deploy de Firebase y la sincronización de `dev` mantienen sus workflows existentes.
