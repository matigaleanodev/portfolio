# Portfolio v1.2.0

Visual and accessibility refresh of the portfolio and blog, improving reading comfort, keyboard navigation, and project presentation.

## Included changes

- More compact blog listing, normalized search, and accessible sorting.
- Editorial typography, lists, tables, and code blocks with highlighting, language labels, and copy controls.
- Long-article table of contents with links available in prerendered HTML.
- Internal links with correct focus and scrolling, visible focus indicators, and Argentine Spanish dates.
- Subscription form fixed to submit through the native form and display accessible errors.
- More compact project cards, expandable architecture details, and a new Portfolio project illustration.
- Nonmodal chat with improved focus, keyboard handling, scrolling, and mobile controls.
- Before/after visual evidence and browser checks for accessibility, content without JavaScript, and actual 200% and 400% zoom.

## Compatibility

The static-first architecture, public routes, and existing API and cloud contracts are preserved. The refresh requires no data migrations or new service configuration.

## Publication

The `release/v1.2.0` branch consolidates the changes into one commit. Its PR to `main` must use squash merge. Once merged, the release workflow creates the annotated `v1.2.0` tag on the integrated `main` commit and publishes these notes in GitHub Releases. Firebase deployment and `dev` synchronization retain their existing workflows.
