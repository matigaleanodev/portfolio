# Portfolio v1.3.0

Contenido editorial, arquitectura y publicación diaria

- Artículos técnicos y profesionales, diagramas interactivos con previews estáticos y evidencias de arquitectura para Portfolio, Modo Playa y Foodly Notes.
- Publicación diaria a las 09:17 de Argentina con filtrado por fecha, borradores excluidos y recuperación cloud aunque no haga falta redeploy de Firebase.
- Historial conversacional acotado, sesión en memoria cuando Storage está bloqueado y analytics sin texto de sugerencias.

## Publicación y compatibilidad

Esta release conserva las rutas y contratos públicos. Las mejoras se integran mediante merge commit para preservar los commits por tema. El tag anotado se publica sobre el commit integrado después de confirmar los despliegues.

Orden de despliegue: Cloud → API → frontend. No adelantar el frontend a sus protecciones de publicación y soporte de historial.
